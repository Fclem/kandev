# Internationalization (i18n)

Kandev's web UI is internationalized with [Lingui](https://lingui.dev). English
is the source locale; a **pseudo-locale** is used for QA. This doc is the
day-to-day reference; the durable requirements live in
[`docs/specs/platform/i18n.md`](specs/platform/i18n.md) and the buildout in
[`docs/plans/i18n/plan.md`](plans/i18n/plan.md).

## TL;DR for adding a string

- **JSX text** → wrap with the `<Trans>` macro:
  ```tsx
  import { Trans } from "@lingui/react/macro";
  <Button><Trans>Create task</Trans></Button>
  ```
- **Attributes / toasts / variables** → use the `t` macro from `useLingui`:
  ```tsx
  import { useLingui } from "@lingui/react/macro";
  const { t } = useLingui();
  toast.success(t`Task created`);
  <input placeholder={t`Search tasks`} aria-label={t`Search`} />
  ```
- **Plurals** → the `Plural` macro:
  ```tsx
  import { Plural } from "@lingui/react/macro";
  <Plural value={count} one="# task" other="# tasks" />
  ```
- **Outside React** (`.ts` utils) → the `t` macro from `@lingui/core/macro`
  (it binds to the global `i18n`):
  ```ts
  import { t } from "@lingui/core/macro";
  export const label = () => t`Saved`;
  ```

Do **not** translate: user/domain data (task titles, chat, diffs, repo names),
code identifiers, `data-testid`, brand/proper nouns (Kandev, GitHub, Jira, …).

## Commands

> Requires **Node 24** (`apps/package.json` `engines`); the Lingui CLI silently
> no-ops on older Node. Run `nvm use 24` first if needed.

```bash
cd apps/web
pnpm extract        # scan source → update src/locales/**/messages.po
pnpm compile        # compile .po → JS (CI check; Vite compiles .po on the fly at build)
pnpm extract:check  # fails if catalogs are out of date (used in CI)
pnpm lint:i18n      # report hardcoded strings (the anti-regression guard)
```

Commit the `.po` catalogs. Compiled catalog JS is git-ignored (the Vite plugin
compiles `.po` imports at build; see `apps/web/vite.config.ts`).

## How it's wired

- **Config**: `apps/web/lingui.config.ts` (locales `en` + `pseudo`, PO format).
- **Build**: `@lingui/vite-plugin` compiles `.po` imports; Lingui macros are
  transformed by `@rolldown/plugin-babel` + `linguiTransformerBabelPreset()`
  (Vite 8 / Rolldown uses oxc, not Babel, so the macro transform is a dedicated
  plugin — see the note in `vite.config.ts`).
- **Runtime**: `apps/web/lib/i18n/` — `i18n` instance, `activateLocale()`,
  `<I18nProvider>` (mounted outermost in `app-shell.tsx`), `resolveInitialLocale`
  (payload → cookie → `en`), and `formats.ts` (locale-aware date/number/relative
  time; `timeAgo` is a deprecated alias for `formatRelative`).
- **Locale source of truth**: the `kandev_locale` cookie. The Go shell
  (`apps/backend/internal/webapp/shell.go`) reads it to set `<html lang>` and the
  boot payload on first paint; the Settings language switcher writes it.
- **Shared UI**: `@kandev/ui` primitives read built-in labels from
  `UIStringsProvider` (English defaults, no i18n dependency). The app feeds
  translations via `lib/i18n/ui-strings-bridge.tsx`.

## Pseudo-locale QA (the completeness oracle)

Switch to **Pseudo (QA)** in Settings → Appearance (dev/e2e builds only). Every
externalized string renders accented and padded, e.g. `Create task` → `Ĉřéàţé
ţàśķ`. Any remaining **plain-English** user-facing text is a string that was not
externalized — that is the acceptance check for the full sweep.

## Adding a real language (future)

1. Add the locale to `locales` in `lingui.config.ts` and `SUPPORTED_LOCALES` +
   `LOCALE_LABELS` in `lib/i18n/index.ts` (and the Go `supportedLocales` map).
2. `pnpm extract` to create `src/locales/<locale>/messages.po`, translate it.
3. The language switcher and formatting pick it up automatically.
